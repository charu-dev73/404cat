# 404cat

> *the official unhinged cat meme archive. nobody asked. we did it anyway.*

## what is this

A multi-page HTML website dedicated to documenting, celebrating, and
dramatically over-analysing the greatest cat memes the internet has
ever produced. Built with pure HTML and inline CSS. Zero frameworks.
Maximum chaos.

## pages

- **index.html** — Hall of Legends, the homepage
- **gallery.html** — full cat archive with lore drops
- **rankings.html** — official power rankings (very scientific)
- **about.html** — origin story, team, FAQ & guestbook

## built with

- HTML
- Inline CSS
- VT323 & Press Start 2P (Google Fonts)

## why

HTML practice project. also the internet needed this.
